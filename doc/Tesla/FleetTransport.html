Overview

Small adapter around TeslaAPI that submits an encoded RoutableMessage to the Fleet API signed-command endpoint and translates non-success HTTP responses into FleetAPIError.

See Also:

  • https://developers.tesla.com/docs/fleet-api

def initialize(

POSTs an encoded RoutableMessage to the Fleet API ‘vehicles/:vin/signed_command` endpoint. The VIN is URI-escaped, configured network timeouts are passed through, and any non-200 response raises FleetAPIError containing the HTTP status and response body.

def signed_command(
  vin:,
  routable_message:
)
  post_data = { "routable_message" => routable_message }
  (response_code, response_body) = @tesla_api.api_request(
    :POST,
    "vehicles/#{CGI.escapeURIComponent(vin)}/signed_command",
    post_data,
    open_timeout:  @open_timeout,
    read_timeout:  @read_timeout,
    write_timeout: @write_timeout
  )

  unless response_code == 200
    raise Tesla::FleetAPIError.new(
      status: response_code,
      body:   response_body
    )
  end

  response_body = {} if response_body.nil?

  response_body
end
